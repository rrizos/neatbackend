{% comment %} Bilingual plumbing shared by the Django-rendered public pages. Deliberately identical to what landing/generate_legal.py emits, so every page on neatapp.gr answers the language question the same way and a choice made on one is honoured by all the others: 1. ?lang=en / ?lang=el — an explicit link 2. localStorage.neatLang — the visitor's own EL/EN choice, site-wide 3. the neat_country cookie — country nginx resolved from their IP 4. browser locale / time zone Which copy is shown is decided in CSS from html[data-lang], set before first paint, so neither language flashes and a browser with JavaScript off still gets a readable Greek page. {% endcomment %}
